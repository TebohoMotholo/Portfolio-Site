# Personal Portfolio Website

A clean, responsive, static portfolio site for Teboho Motholo covering skills, experience, projects and background. Built with HTML, CSS and vanilla JavaScript.

## Features

- Animated skill cards with scroll-triggered progress bars
- Particle.js background effects
- Responsive grid layouts for projects and skills
- Expandable employment history
- Contact form with validation (Formspree)

## Pages

Home, About, Education, Skills, Experience, Projects, Contact.

## Hosting

- Primary: Netlify, deployed from this repository
- Planned: self-hosted copy on a Proxmox web server, with Netlify kept as a backup
