Case study

Network imaging with FOG

A production imaging server that installs a standard Windows build on contact centre PCs over the network.

  • Redial BPO
  • In production
  • FOG Project
  • Ubuntu Server LTS
  • Sophos XGS136

Goal

Image the Windows PCs on the contact centre floor over the network from one captured reference image, so every machine starts from the same build.

How a PC boots into imaging

Hover, tap or tab to a block for details.

What I built

  • A FOG (Free Open-source Ghost) server on Ubuntu Server LTS, running on an Intel i5 machine with 16 GB RAM and a 256 GB SSD, with a static IP address.
  • Network boot through the Sophos XGS136 firewall (SFOS 22.0.1): the DHCP scope uses the Next server and Boot file options, pointing PCs at the FOG server and ipxe.efi.
  • A captured reference Windows image, plus host registration so a PC is recognised when it boots.
  • An end-to-end test: a registered PC network booted, pulled the image and finished deployment.

Outcome

The server is in production at Redial BPO and images floor PCs with Windows. The reference image is captured, and a test PC has been registered and imaged end to end.
