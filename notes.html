Network booting FOG from a Sophos firewall

November 2026 | FOG, Sophos XGS, DHCP

When the firewall runs DHCP instead of the FOG server, PCs need two extra DHCP options so they know where to boot from.

  1. Give the FOG server a static IP address.
  2. In the firewall DHCP scope, set Next server to the FOG server's IP address.
  3. Set Boot file to ipxe.efi for UEFI PCs. Older BIOS PCs use undionly.kpxe. Both files are served from /tftpboot on the FOG server.
  4. Network boot a test PC. It should load iPXE and show the FOG menu.

If a PC stops with PXE-E53: No boot filename received, the Boot file option is missing or not reaching the client. iPXE usually also needs Secure Boot turned off in the PC firmware. Field names in the firewall can differ slightly between firmware versions.

Error 53003: blocked by Conditional Access

November 2026 | Entra ID, Conditional Access, Intune

Error 53003 means a Conditional Access policy blocked the sign-in. The device or user did not meet a condition the policy requires, for example a compliant or registered device, MFA, or an approved app.

  1. Open the failed sign-in in the Entra ID sign-in logs.
  2. On the Conditional Access tab, find the policy marked as failed. That is the policy that blocked it.
  3. Check the Device info tab. An unregistered phone usually shows no device ID, so it cannot satisfy a policy that needs a compliant device.
  4. Either enrol the device (for example through the Company Portal app) so it can become compliant, or review whether the policy should apply to that user, app or platform.
  5. Use the What If tool to check the result before changing the policy.

Packaging an app for Intune with the IntuneWin tool

November 2026 | Intune, Win32 apps

Intune installs Windows apps from a .intunewin package, which the Microsoft Win32 Content Prep Tool creates from the installer.

  1. Put the installer and any supporting files in one source folder.
  2. Run the tool against that folder: 
    IntuneWinAppUtil.exe -c C:\Source\App -s setup.exe -o C:\Output
  3. In Intune, add a Windows app (Win32) and upload the .intunewin file.
  4. Set the install and uninstall commands, for example msiexec /i app.msi /qn for an MSI.
  5. Add a detection rule so Intune knows the app is installed, such as the MSI product code, a file or a registry key.
  6. Assign it to a small pilot group first, check it on a device, then widen the assignment.
